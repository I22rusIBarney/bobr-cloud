# 🦫 Bobr Cloud

**Telegram-бот и мини-приложение для продажи VPS под своим брендом.** Серверы создаются через реселлерский API [Astra VPS](https://astravps.co/reseller), оплата — через ЮKassa (карта, СБП), чеки самозанятого уходят в «Мой налог» автоматически.

Клиент выбирает конфигурацию → платит с баланса → через 1–3 минуты получает IP и пароль. Дальше бот сам продлевает сервер, напоминает об оплате, списывает автоплатёж с сохранённой карты и отвечает на обращения. Всё управление — в админке внутри Telegram.

---

## Возможности

**Для клиентов**
- Бот: покупка сервера, пополнение баланса, список серверов и управление ими, поддержка.
- Личный кабинет (Telegram Mini App, тёмная тема):
  - конструктор сервера: локации, готовые тарифы Starter / Basic / Standard / Performance, ползунки CPU · RAM · NVMe;
  - серверы: IP и пароль, включение / выключение / перезагрузка, VNC, переустановка ОС, сброс пароля, смена IP, увеличение мощности, переименование, удаление с возвратом за неиспользованные дни;
  - профиль: баланс, пополнение, промокоды, способы оплаты и автоплатёж, история операций с чеками, документы;
  - обращения в поддержку в виде чата;
  - реферальная программа: ссылка-приглашение, бонусы на баланс;
  - оформление: фоны и сезонные эффекты (снег, Новый год, Хэллоуин, листопад, весна, сердечки, конфетти).
- Полноэкранный режим на телефонах, учёт вырезов и системных кнопок Telegram.

**Для владельца**
- Админка в Telegram: сводка (маржа, оборот, баланс Astra), наценка и округление цен, скрытие тарифов, лимиты, возвраты, режим «продажи закрыты».
- Клиенты: карточка с услугами, платежами, картами, согласиями и рефералами; изменение баланса, бан, отключение наценки для друзей.
- Обращения: переписка, внутренние заметки, передача технической проблемы в поддержку Astra одной кнопкой.
- Промокоды: бонус на баланс или скидка на покупку, лимиты и сроки.
- Документы: оферта, правила, политика конфиденциальности, согласие на обработку ПДн, правила автоплатежей; журнал согласий.
- Интеграции ЮKassa и «Мой налог» настраиваются прямо в админке.
- Алерты: низкий баланс у Astra, сбои выдачи, чеков и автоплатежей.

## Установка

Нужны: VPS с Ubuntu или Debian, домен с A-записью на IP сервера, свободные порты 80 и 443, токен бота от [@BotFather](https://t.me/BotFather) и реселлерский ключ Astra.

```bash
git clone https://github.com/I22rusIBarney/bobr-cloud.git
cd bobr-cloud
sudo ./install.sh
```

Установщик сам поставит Docker и спросит только основное, проверяя каждое значение: токен бота, ваш Telegram ID, домен (сверит DNS с IP сервера) и ключ Astra. Затем поднимет бота с автоматическим HTTPS (Caddy + Let's Encrypt).

| Команда | Что делает |
|---|---|
| `sudo ./install.sh` | установка или повторная настройка (прошлые значения подставляются по Enter) |
| `sudo ./install.sh update` | подтянуть обновления из git, пересобрать и перезапустить |
| `sudo ./install.sh logs` | логи бота |
| `sudo ./install.sh status` | состояние контейнеров |

## Первая настройка

Откройте бота → `/start` → **⚙️ Админка** (или команда `/admin`):

1. **Подключения → ЮKassa** — shopId и секретный ключ, «Сохранить и проверить». Скопируйте показанный URL уведомлений в кабинет ЮKassa → Интеграция → HTTP-уведомления, события `payment.succeeded` и `payment.canceled`.
2. **Подключения → Мой налог** — ИНН и пароль от lknpd.nalog.ru (по желанию).
3. **Документы** — ФИО, ИНН, почта, «Опубликовать новую редакцию».
4. **Цены** — наценка, добавка, округление; **Тарифы** — что показывать клиентам.
5. После того как ЮKassa подключит рекуррентные платежи — **Продажи → Автоплатежи**.

Ключи хранятся в базе `data/bot.db` на вашем сервере; ограничьте доступ к папке `data/`.

## Как это работает

- **Цены.** Каталог и себестоимость берутся из API Astra (уже со скидкой реселлера), обновляются раз в минуту. Цена клиенту = себестоимость × (1 + наценка) + добавка, с округлением вверх. Уже купленные серверы продлеваются по цене на момент покупки.
- **Баланс.** Все услуги оплачиваются с внутреннего баланса; пополнение — через ЮKassa (вебхук + страховочная проверка каждую минуту).
- **Автопродление.** За сутки до окончания срока стоимость списывается с баланса; если не хватает и включён автоплатёж — недостающая сумма списывается с сохранённой карты. Напоминания — за 3 дня и за 1 день.
- **Чеки.** После каждого пополнения формируется чек самозанятого через неофициальную библиотеку `nalogovich` (`app/nalog.py`), с повторами и алертом при сбое.
- **Рефералы.** Пригласивший получает процент с пополнений друга в течение заданного срока, приглашённый — бонус после первой оплаты. Только на баланс, настраивается в админке.
- **Поддержка.** Любое сообщение боту становится обращением; ответы приходят в чат и в кабинет.

## Структура

```
app/
  bot.py          — Telegram-бот (aiogram 3)
  services.py     — покупка, продление, платежи, автоплатежи, фоновые задачи
  astra.py        — клиент реселлерского API Astra
  yookassa.py     — клиент ЮKassa
  nalog.py        — чеки «Мой налог»
  account.py      — согласия, промокоды, история, карточка клиента
  tickets.py      — обращения в поддержку
  referral.py     — реферальная программа
  legal.py        — шаблоны документов
  web/
    server.py     — FastAPI: вебхук, админ-API, публичные страницы
    cabinet.py    — API личного кабинета
    cabinet.html  — личный кабинет (Mini App)
    admin.html    — админка (Mini App)
    static/       — дизайн-система (ui.css, ui.js) и сезонные эффекты (fx.js)
main.py           — запуск бота, веб-сервера и фоновых задач
install.sh        — установщик
```

Стек: Python 3.12, aiogram 3, FastAPI, SQLAlchemy 2 (SQLite), httpx; Docker Compose + Caddy.

## Перед боевым запуском

- Сделайте тестовое пополнение на 100 ₽: деньги зачислились, чек появился в «Мой налог». Если ЮKassa сама отправляет чеки самозанятого, выключите наши («Продажи → Чеки после пополнения»), чтобы не было дублей.
- Баланс Astra пополняется вручную и должен покрывать продажи и автопродления; бот предупредит, когда он ниже порога.
- **Документы — шаблоны.** Проверьте их у юриста (тексты в `app/legal.py`). Учтите требования 152-ФЗ: уведомление Роскомнадзора об обработке ПДн и локализация баз данных граждан РФ.
- Следите за лимитом дохода самозанятого.

## Ограничения

- Одна инстанция процесса (SQLite). Для масштабирования — Postgres (`DATABASE_URL=postgresql+asyncpg://…` и пакет `asyncpg`).
- Период аренды — 30 дней.
- Если запрос к Astra оборвался по таймауту, итог неизвестен: деньги автоматически не возвращаются, админ получает алерт и решает вручную.
