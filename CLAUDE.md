# Bobr Cloud — правила для изменений

## Версии и история изменений

Версия бота живёт в `app/changelog.json` (новые выпуски сверху). Каждый PR, который меняет поведение для
пользователя или администратора, добавляет запись или дополняет верхнюю, если она ещё не выпущена:

- **+0.1** — минорное: новая настройка, улучшение, исправления (1.0 → 1.1).
- **+1.0** — крупное: новая большая возможность или заметная переделка (1.1 → 2.0).
- Пункты `items`: `kind` — `new` (новое), `better` (лучше), `fix` (исправлено); текст — по-русски, для людей,
  без внутренних названий функций и файлов.
- Тест `tests/test_system.py::test_changelog_format` проверяет порядок и формат.

После обновления бот сам пишет администраторам, что нового, — по этой истории.

## Журнал действий

Изменяющие запросы админки пишутся в журнал сами (`app/audit.py`, список `ROUTES`). Новый изменяющий эндпоинт
`/api/admin/…` — добавьте его в `ROUTES` с понятным названием действия.
